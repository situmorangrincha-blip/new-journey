# JKS Time Planner

Isi zip ini (semua harus ada di root repo GitHub, TANPA folder):
- index.html
- vercel.json
- README.md

Upload ke GitHub: buka repo, Add file > Upload files, pilih 3 file di atas, Commit.
Di Vercel: Import repo, biarkan semua setting default (Framework "Other"), Deploy.
Kalau sudah pernah deploy: Deployments > titik tiga > Redeploy.
